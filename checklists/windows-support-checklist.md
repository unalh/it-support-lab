# Windows Support Checklist

A general checklist for Windows support tasks to ensure consistency when troubleshooting issues.

- Verify physical connections (power, network, peripherals).
- Confirm the user’s problem description and any error messages.
- Check Windows update status and install pending updates.
- Verify antivirus definitions are up to date.
- Review Device Manager for hardware issues.
- Check Event Viewer for recent system or application errors.
- Run Disk Cleanup and check available disk space.
- Verify backup status and restore points.
- Document the issue and steps taken.
